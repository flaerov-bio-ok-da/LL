# LeonMenu (TrollStore .tipa)

Плавающее меню «Legit Cheat | TenrySoft» поверх всех приложений и игр.

- **START**: запускает оверлей, меню открывается сразу.
- Меню перетаскивается за шапку или нижнюю полоску. Вкладки Player / Weapon / Other / Visuals, галочки с анимацией.
- **×** в правом верхнем углу: меню плавно сворачивается в Леона.
- **Леон**: тап открывает меню, его можно перетаскивать, он прилипает к краю экрана.
- **STOP** в приложении: выключает оверлей.

> Галочки визуальные: они ничего не меняют в играх.

## Сборка через GitHub (без Mac)

1. Создайте новый репозиторий на GitHub и загрузите в него **содержимое** этой папки (вместе с `.github`).
2. Откройте вкладку **Actions**, выберите **Build LeonMenu.tipa** и нажмите **Run workflow** (сборка также запускается сама после каждого push).
3. Через 3–5 минут в разделе **Artifacts** появится `LeonMenu`. Скачайте zip, внутри лежит `LeonMenu.tipa`.
4. Откройте `LeonMenu.tipa` на iPhone через TrollStore и нажмите Install.

## Требования

- TrollStore (iOS 14.0 – 16.6.1, 16.7 RC, 17.0).

Оверлей основан на открытом проекте TrollSpeed (MIT, см. `LICENSE-TrollSpeed`).
